### 💡 Моя экспертиза

**QA и автоматизация**

*   **Full-Cycle Testing:** Unit, Integration, E2E, API, UI/UX, Performance (Load & Stress), Regression, UAT.
*   **Automation:** Разработка скриптов и фреймворков с нуля на базе Selenium и Playwright.
*   **Performance Analysis:** Оптимизация приложений с помощью Lighthouse и GT Metrix.
*   **QA Documentation:** Создание полного комплекта документов: Test Strategy, Test Plans, Test Cases, Coverage Matrices.
*   **CI/CD:** Интеграция автоматизированных тестов в пайплайны для непрерывного контроля качества.
*   **AI in QA:** Активное применение AI-инструментов для повышения эффективности тестирования.

**DevOps и инфраструктура**

*   **Linux и сети:** администрирование, systemd, диагностика сбоев, Bash-скрипты.
*   **CI/CD:** конвейеры сборки, публикации артефактов и деплоя на GitLab CI и GitHub Actions.
*   **Инфраструктура как код:** роли Ansible (Redis, Grafana, окружения dev/prod), Terraform/OpenTofu.
*   **Контейнеры:** Docker, образы, сети, тома.
*   **Домашняя лаборатория:** Proxmox, Windows Server (AD DS), Linux, PostgreSQL, Nexus.
